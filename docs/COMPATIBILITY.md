# Compatibility

Generated by `tools/kb.py docs` from `kb/*.toml` and `kb/presence.json` (which `tools/spec-check.py --kb` writes from extracted LG firmware). Do not edit by hand.

The webOS release decides the service set far more than the model: one image per chip platform and version is shipped to every region. Presence is per webOS generation across the surveyed images (5.6, 6.5, 8.3, 9.2, 10.3, 11.2): ● on every image of that generation, ◐ on some, · on none.

Presets: Recommended, Strict, Lockdown. Since 1.4.

### LAN firewall (`lan`)

Closes the TV to all inbound connections from your local network. **Breaks:** SSH, AirPlay, Google Cast, phone apps, Screen Share, network devices in Universal Control. Replies to connections the TV makes itself (streaming, browsing) still get through. IPv6 is off while it is on (the firewall cannot filter it). `oyg lan allow <ip>` lets a device through, for example your computer for SSH; otherwise turn the firewall off from the app on the TV.

Presets: Strict, Lockdown. Since 1.4.

## Never touched

These stay whatever the preset:

- sdx: binding it silently kills the Settings UI; the gateway is filtered by table instead
- eplmanager: OLED pixel care; stopping it risks the panel
- captureservice: shared by pixel care and every screen capture
- iconnectivity (soft): Universal Control and the IR blaster; binding it broke external-speaker control and made Settings take ~8 s
- /dev/hidraw*: every remote button rides on it
- interpreters and launchers: shared by everything
- lgtvonline.lge.com: ConnMan's online check; without it the TV thinks it is offline
- ngfts: the terms-and-conditions UI loads from it and shows 'system error' when it is sinkholed
- <CC>/<RIC>.tv.wiselg.com: webOS 11 carries sign-in, the clock and the Store on it; only the gateway table can separate telemetry
- <CC>.nextlgsdp.com / lgtvsdp.com: LG's clock rides on them; sinkholing broke TLS once (clock fell back to 2021)
- <CC>.app.lgwebostv.com: the Content Store
- snu/su.lge.com: firmware updates are Homebrew Channel's toggle, the owner's call

Gateway names: `sdp_auth`, `sdp_init`, `sdp_common`, `device_keys`.
